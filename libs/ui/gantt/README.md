# @semantic-components/ui/gantt

A Gantt chart for the Semantic Components library: a timeline column for the [Data Table](../data-table/README.md) — bars, progress, summaries, milestones, links and markers, moved by drag or from the keyboard.

## Contents

- **Components**: Gantt, timeline cell, scale, bar, marker, links

## Usage

```ts
import { ScGantt, ScGanttBar, ScGanttLinks, ScGanttMarker, ScGanttScale, ScGanttTimeline } from '@semantic-components/ui/gantt';
```
