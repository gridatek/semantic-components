# @semantic-components/editor

Rich text editor components built on top of Tiptap for the Semantic Components library.

## Contents

- **Components**: Editor (a Signal Forms control), content, toolbar, command buttons (bold, italic, underline, strikethrough, code, lists, blockquote, alignment, horizontal rule, clear formatting, undo/redo, link), heading, word/char count
- **Styles**: ProseMirror editor styles

## Usage

```ts
import { ScEditor, ScEditorBold, ScEditorContent, ScEditorToolbar } from '@semantic-components/editor';
```

See [the editor's README](src/lib/components/editor/README.md).
