# @semantic-components/ui/barcode-scanner

Barcode and QR code reading for the Semantic Components library: the browser's `BarcodeDetector`, or `barcode-detector`'s (an optional peer) where it has none, loaded on the first scan.

## Contents

- **Components**: Barcode Scanner, video, overlay, toggle, file input
- **Setup**: `withBarcodeScanner()` — where the decoder is served

## Usage

```ts
import { ScBarcodeScanner, ScBarcodeScannerFile, ScBarcodeScannerOverlay, ScBarcodeScannerToggle, ScBarcodeScannerVideo } from '@semantic-components/ui/barcode-scanner';
```
