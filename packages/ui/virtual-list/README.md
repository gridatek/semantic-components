# @semantic-components/ui/virtual-list

A long list rendered only where it is seen, for the Semantic Components library, on [TanStack Virtual](https://tanstack.com/virtual)'s engine (`@tanstack/virtual-core`, an optional peer of ui: install it where you use this entry).

## Contents

- **Components**: Virtual list, row

## Usage

```ts
import { ScVirtualList, ScVirtualListRow } from '@semantic-components/ui/virtual-list';
```
